Basic Computer Science

Chapter 1

What is Computer Science?

Computer science is not just about programming. It is the study of computation, information, and automation — how problems are represented, how solutions are designed as step-by-step procedures (algorithms), and how those procedures are carried out by machines.

Core pillars

  • Hardware: The physical machine — CPU, memory, storage, and input/output devices.
  • Data: How information is represented using bits, bytes, and number systems.
  • Software: Programs and operating systems that control the hardware.
  • Algorithms: Step-by-step procedures for solving problems efficiently.
  • Networking: How computers communicate and share resources.

Why start here?

Understanding the foundations makes every other tutorial easier. When you later learn Python, C++, databases, or operating systems, you will already know what happens under the hood: memory layout, CPU execution, binary data, and algorithmic cost.

Chapter 2

How Computers Work (Hardware)

Every computer, from a phone to a supercomputer, follows the same basic model: input → process → store → output.

Key components

Component Role
CPU (processor) The "brain." Fetches, decodes, and executes instructions. Measured in clock speed (GHz) and cores.
RAM (memory) Fast, volatile working storage for programs and data currently in use. Lost when power is off.
Storage (SSD/HDD) Slower, non-volatile storage for files and the OS. Survives reboots.
GPU Specialized processor for parallel math — graphics, machine learning, scientific simulation.
Motherboard Main circuit board connecting CPU, RAM, storage, and peripherals.
I/O devices Keyboard, mouse, screen, network, speakers — how the computer interacts with the world.

The fetch-decode-execute cycle

The CPU repeatedly performs three steps for every instruction:

  1. Fetch: Get the next instruction from memory.
  2. Decode: Figure out what the instruction means.
  3. Execute: Carry out the instruction (math, move data, jump, etc.).

This happens billions of times per second. Software is ultimately a sequence of these simple instructions.

Chapter 3

Data & Binary Representation

Computers store everything as bits — 0s and 1s representing low/high voltage. Eight bits make a byte.

Number systems

Decimal (base 10)
Digits: 0–9

Humans use base 10 because we have ten fingers.

Binary (base 2)
Digits: 0, 1

Computers use base 2 because transistors are on/off.

Hexadecimal (base 16)
Digits: 0–9, A–F

Compact shorthand for binary (one hex digit = 4 bits).

Converting binary to decimal

Each bit position represents a power of 2, from right to left:

# Convert binary 1011 to decimal
#  1*2^3 + 0*2^2 + 1*2^1 + 1*2^0
#  = 8 + 0 + 2 + 1 = 11

binary = "1011"
decimal = 0
for i, bit in enumerate(reversed(binary)):
    decimal += int(bit) * (2 ** i)

print(f"Binary {binary} = decimal {decimal}")
# Output: Binary 1011 = decimal 11

Chapter 4

Operating Systems

An operating system (OS) is the layer between applications and hardware. It manages resources so programs don't have to talk to the CPU, RAM, or disk directly.

OS responsibilities

  • Process management: Runs programs, schedules CPU time, and handles multitasking.
  • Memory management: Allocates and frees RAM for each program.
  • File system: Organizes files and folders on storage.
  • Device drivers: Lets software use printers, networks, GPUs, etc.
  • User interface: Command line (CLI) or graphical (GUI) for people to interact.

Common operating systems

Linux

Open source, powers servers, Android, supercomputers.

Windows

Most common desktop OS for home and office.

macOS

Apple's desktop OS, Unix-based.

Networking lets computers exchange data. The Internet is a global network of networks built on shared protocols.

Key concepts

Domain nameHuman-readable name (e.g. example.com), resolved by DNS.
HTTP/HTTPSProtocols for transferring web pages (HTTPS is encrypted).
TCP/UDPTransport protocols — TCP is reliable, UDP is fast.

Chapter 6

Algorithms & Complexity Basics

An algorithm is a precise, step-by-step procedure for solving a problem. Not all algorithms are equal — some are far faster than others.

Big O notation

Big O describes how an algorithm's runtime grows as input size n grows. Common classes:

Big O Name Example
O(1)Constant timeArray index access
O(log n)LogarithmicBinary search
O(n)LinearSimple loop / search
O(n log n)LinearithmicMerge sort, quick sort average
O(n²)QuadraticNested loops, bubble sort

Linear vs binary search (Python)

# Linear search: check every element (O(n))
def linear_search(arr, target):
    for i, value in enumerate(arr):
        if value == target:
            return i  # found at index i
    return -1         # not found

# Binary search: requires sorted array (O(log n))
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

data = [2, 5, 8, 12, 16, 23, 38, 45, 56, 67, 78]
target = 23

print("Array:", data)
print("Target:", target)
print("Linear search index:", linear_search(data, target))
print("Binary search index:", binary_search(data, target))
# Output:
# Array: [2, 5, 8, 12, 16, 23, 38, 45, 56, 67, 78]
# Target: 23
# Linear search index: 5
# Binary search index: 5

Chapter 7

Programming Fundamentals

Programming is writing algorithms in a language a computer can execute. Python is a great first language because it reads like English.

Core concepts

  • Variables: Named containers that hold data.
  • Data types: Integers, floats, strings, booleans, lists, dictionaries.
  • Control flow: if/else, for loops, while loops.
  • Functions: Reusable, named blocks of code.
  • Debugging: Finding and fixing errors in programs.

Your first Python program

# Greet the user and do a small calculation
name = input("What is your name? ")
age = int(input("How old are you? "))

print(f"\nHello, {name}! 👋")
print(f"You are {age} years old.")
print(f"In 10 years, you will be {age + 10}.")

# Simple loop example
print("\nCounting to 5:")
for i in range(1, 6):
    print(f"  {i}")

print("\nDone! Welcome to computer science. 🎓")

Capstone Project

Build a "Computer Basics" Explorer

Create an interactive Python program that teaches computer science basics: number conversion, component lookup, and a mini quiz. All runnable by copying the code.

Phase 1 — Number converter

Convert decimal to binary and hex with clear output.

Phase 2 — Hardware database

A dictionary of components the user can look up.

Phase 3 — Binary quiz

Ask the user to convert decimal to binary; check answers.

Phase 4 — Interactive menu

Loop until the user chooses to exit.

Phase 5 — Polish & run

Add comments, formatting, and a friendly goodbye message.

Complete capstone code

"""Computer Basics Explorer — interactive capstone project.
Run this file with: python basics_explorer.py
"""

# --- Hardware database: name -> description ---
HARDWARE = {
    "CPU": "Executes instructions. The brain of the computer.",
    "RAM": "Fast, temporary memory for running programs.",
    "Storage": "Long-term storage for files and the operating system.",
    "GPU": "Handles graphics and parallel math.",
    "Motherboard": "Connects all components together.",
}

# --- Phase 1: number converter ---
def to_binary(n):
    """Return the binary string of a non-negative integer."""
    if n == 0:
        return "0"
    bits = []
    while n > 0:
        bits.append(str(n % 2))
        n //= 2
    return "".join(reversed(bits))

def to_hex(n):
    """Return the hexadecimal string of a non-negative integer."""
    if n == 0:
        return "0"
    digits = "0123456789ABCDEF"
    chars = []
    while n > 0:
        chars.append(digits[n % 16])
        n //= 16
    return "".join(reversed(chars))

# --- Phase 3: binary quiz ---
def binary_quiz():
    import random
    score = 0
    for _ in range(3):
        n = random.randint(0, 255)
        correct = to_binary(n)
        ans = input(f"Convert decimal {n} to binary: ").strip()
        if ans == correct:
            print("  ✅ Correct!")
            score += 1
        else:
            print(f"  ❌ Close. Correct answer: {correct}")
    print(f"Quiz score: {score}/3\n")

# --- Phase 2 & 4: interactive menu ---
def lookup_hardware():
    print("\nAvailable components:", ", ".join(HARDWARE.keys()))
    choice = input("Which component do you want to know about? ").strip().upper()
    print(f"  {choice}: {HARDWARE.get(choice, 'Not found.')}\n")

def main():
    print("=== Computer Basics Explorer ===\n")
    while True:
        print("1. Convert a number (decimal → binary / hex)")
        print("2. Look up a hardware component")
        print("3. Take a 3-question binary quiz")
        print("4. Exit")
        choice = input("\nChoose an option (1-4): ").strip()

        if choice == "1":
            try:
                n = int(input("Enter a non-negative integer: "))
                if n < 0:
                    print("Please enter a non-negative number.\n")
                    continue
                print(f"  Decimal: {n}")
                print(f"  Binary:  {to_binary(n)}")
                print(f"  Hex:     {to_hex(n)}\n")
            except ValueError:
                print("That's not a valid integer.\n")
        elif choice == "2":
            lookup_hardware()
        elif choice == "3":
            binary_quiz()
        elif choice == "4":
            print("\nGoodbye! Keep exploring computer science. 🎓")
            break
        else:
            print("Invalid choice. Try again.\n")

if __name__ == "__main__":
    main()

# 4. Exit

#   Hex:     2A
